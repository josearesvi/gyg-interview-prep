# Software Engineer Backend Coding Interview

## Requirements
- JDK 21

## Local setup

### Running the application with IntelliJ IDEA
1. Clone this repository
2. Import it as a new project in IntelliJ
3. Open `GetYourGuideApplication.java` and run the `main` method with the green arrow in the gutter

### Running the application with Maven
```
./mvnw spring-boot:run
```

> We recommend running the application from IntelliJ IDEA so you can use its debugger.

### Other IDEs
Any IDE is fine, as long as you can run the application, call its endpoints and use a debugger.

The endpoints are available at `http://localhost:8080/`.
